All distributed numerical files are copied byte-for-byte. Data are never regenerated by the download or preprocessing commands.

The simulator represents a serviced half bridge/DC-link system: target capacitor C1, capacitor C2, switches Q1/Q2, and thermal regions H1/H2. There are 256 independent parameter families, 8,192 lifecycles and 12,165,120 synchronized observations. Each family owns eight layouts, two coupling designs and two duty settings; `variant = layout*4 + isolation_index*2 + duty_index`. Split assignment is by whole family. Frozen generation settings and family/sampling seeds are in `fh_liteformer/configs/generation.json`.

## Stored fields

`families/f<id>/visible.npz` contains the six predictor keys below. Each sample uses at most 31 irregular current/past observations within 24 h. Valid observations occupy a contiguous prefix; right padding is zero.

| Key | Shape | Meaning |
|---|---|---|
| `values` | N × 31 × 6 × 7, float32 | Measurements and installed ratings in the order below |
| `conditions` | N × 31 × 5, float32 | Current command, duty, switching frequency, ambient temperature, fan command |
| `relative_time` | N × 31, float32 | Hours relative to the current endpoint, from −24 to 0 |
| `padding_mask` | N × 31, bool | True means a padded timestep |
| `feature_missing_mask` | N × 6 × 7, bool | True means an unavailable/type-padding feature; broadcast across time |
| `mounts` | N × 4, int64 | Physical mounting of C1/C2/Q1/Q2 to H1 or H2 |

The fixed role order is C1, C2, Q1, Q2, H1, H2. The feature mask is separate from temporal padding. Masked zero is not a physical zero.

| Type | Channels in order | Units |
|---|---|---|
| C1/C2 | capacitance estimate; ESR estimate; ripple RMS; case temperature; branch ballast; nominal mount resistance; nominal case-ambient conductance | F; Ω; A; °C; Ω; K/W; W/K |
| Q1/Q2 | current RMS; on-resistance estimate; transition-time estimate; case temperature; duty fraction | A; Ω; s; °C; dimensionless |
| H1/H2 | temperature; airflow estimate; fan command; rated sink conductance; rated sink storage | °C; normalized airflow; dimensionless; W/K; J/K |

The last two storage slots of each Q/H node are semantically absent and masked. The five conditions are `load_current_a`, `duty_fraction`, `switching_frequency_hz`, `ambient_temperature_c`, and `fan_command`.

`metadata.npz` stores offline family/layout/design/scenario/variant identities, clocks, raw indices and `fit_eligible`. Metadata are used for grouping and window construction, never as numeric model features. Absolute age, family IDs, future values, hidden damage/path states and EOL information are excluded from predictors.

`targets/<split>/f<id>.npz` stores `reference_rul_h`, `reference_observed`, `censor_flag`, `reference_lower_bound_h`, and `terminal_reason`. Only `reference_observed=True` entries have supervised point RUL labels. Other point targets are NaN, with censoring bounds stored separately. Reason 1 is observed C1 EOL; reasons 0 and 2–5 represent right censoring/domain or auxiliary termination. Auxiliary termination is never relabeled as target failure.

Reference RUL is a deterministic current-operating-policy continuation: preserve the current physical state, intrinsic parameters and topology; maintain current load, duty, ambient, fan and frequency; add no new exogenous fault. EOL is the first C1 damage/loss threshold of 0.20. Synthetic hours are accelerated simulation units and are not a validated field-life scale. This target differs from the standardized Reference policies of earlier simulation studies.

## Graphs and normalization

`graph_manifest.json` retains the actual topology for each layout. The six directed relation types are `bank_parallel`, `cap_mount`, `mount_cap`, `switch_mount`, `mount_switch`, and `thermal_bridge`. Reverse mount relations are explicit. There is no direct switch-to-capacitor shortcut and no added self-loop. Three message-passing layers preserve the longest physical information route into C1.

`preprocess` fits equal-family moments on eligible Training observations only, shared across nodes of the same physical type. Missing/type-padding channels and padded timesteps stay zero after scaling. Conditions use equal-family valid-timestep moments; relative time is divided by 24. The RUL divisor is the equal-Training-family mean, **7286.313336416063 h**. The frozen statistics are shipped in `fh_liteformer/configs/preprocessing.json`. Every cross-fit estimates its own statistics without its held families.

The processed archive contains all visible windows, masks, metadata, targets, the family allocation, graph manifest and original hash manifest. The supplement contains the unchanged `raw_visible` observations and separate `hidden` simulator/audit arrays. Hidden arrays are never loaded by training, prediction or evaluation.

Four original execution/audit JSON files are intentionally excluded: `preflight.json`, `source_binding.json`, `formal_specification.json`, and `generation.json`. `preflight.json` contains private machine paths; the other files contain internal execution/source records. The original hash manifest remains unchanged and still records their hashes. Scientific population/sampling/target settings are supplied as extracted metadata in `configs/generation.json`; this is not a regenerated dataset. The verifier checks the explicitly distributed subset, including every numerical file when the supplement is present.

Only independently generated simulation files are included. Third-party NASA/CES and Aalborg observations and their processed derivatives are not included.
